01 / WHY

Stop doing
Finder archaeology.

macOS knows which apps can open a file. It just makes that knowledge hard to inspect. Dutis reads application metadata directly and puts the answer in one focused terminal flow.

05 / EXAMPLES

Useful answers.
Before changes.

Which app opens PDF files?

Read the current default with dutis get pdf --json. Use dutis query pdf --json to find applications that declare support.

Can I preview a different default?

Run dutis set md com.microsoft.VSCode --dry-run --json to preview a change. A real non-interactive change requires --yes.

Does Dutis handle links as well as files?

Yes. Dutis supports file extensions, UTIs, MIME types, and URL schemes such as https. It can also inspect role-specific Launch Services defaults.

How is Dutis related to duti?

Dutis uses duti to make changes and adds discovery, review, verification, snapshots, JSON output, and an MCP server.
