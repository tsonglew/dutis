01 / WHY

Stop doing
Finder archaeology.

macOS knows which apps can open a file. It just makes that knowledge hard to inspect. Dutis reads application metadata directly and puts the answer in one focused terminal flow.

02 / CAPABILITIES

Small utility.
Sharp edges.

01
Applications 124

Find every application

Scans system, shared, nested, and user application folders while preserving the exact bundle path.

02
.rs.md.pdf

Read real metadata

Understands legacy document types and modern imported or exported UTI declarations.

03
✓

Trust, then verify

Every change is read back from Launch Services before Dutis reports success.

03 / FLOW

Three moves.
No guesswork.

  1. 01

    Type an extension

    Enter md, pdf, html, or any valid file extension.

  2. 02

    Choose the app

    Pick from declared handlers or browse every application installed on your Mac.

  3. 03

    Confirm the result

    Dutis applies the association and verifies the resulting bundle identifier.

Full control.
