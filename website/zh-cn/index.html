TERMINAL / 先查询，再修改

# 查看 PDF 的默认应用
dutis get pdf --json

# 查找支持 PDF 的应用
dutis query pdf --json

# 预览 Markdown 默认应用的修改
dutis set md com.microsoft.VSCode --dry-run --json

预览不会修改系统；实际修改需要明确确认，Dutis 会在操作后验证结果。

01 / 使用场景

先弄清楚。
再做决定。

查询文件的默认打开方式

使用 dutis get pdf --json 查看当前默认应用；用 dutis query pdf --json 查找声明支持该文件类型的应用。

预览默认应用的修改

例如运行 dutis set md com.microsoft.VSCode --dry-run --json。非交互式实际修改需要明确传入 --yes。

管理文件类型和链接

支持扩展名、UTI、MIME 类型和 URL scheme；也可检查 macOS Launch Services 中不同角色的默认应用。

与 duti 有什么关系？

Dutis 使用 duti 执行修改，并提供应用发现、变更预览、结果验证、快照、JSON 输出和 MCP 服务。

02 / AI AGENT

让 Agent 帮忙。
决定权仍在你。

Dutis 适合让 Agent 查询 macOS 文件关联、查找可用应用和预览变更。Skill 需要单独安装；MCP 服务包含在 CLI 中，需要在客户端注册。

01 / SKILL

安装 Agent Skill

安装 Dutis CLI 后，可将 Skill 安装给 Codex 或 Claude Code，指导 Agent 依次检查、预览、请求确认和验证。

npx skills add tsonglew/dutis --skill dutis

skills.sh ClawHub Skill 源码

02 / MCP

连接本地 MCP 服务

MCP 默认提供只读的查询和规划工具。写入工具需要显式启用，并经过服务端授权。

codex mcp add dutis -- dutis mcp
